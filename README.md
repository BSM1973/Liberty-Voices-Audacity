# Voices Audacity v0.5.0 — Liberty Music Software
Development prototype, not for commercial distribution. JUCE 8.0.10 / C++17.

Build on macOS: `cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_OSX_ARCHITECTURES=arm64 && cmake --build build --config Release --parallel 2`.
Windows: `cmake -S . -B build -A x64` then `cmake --build build --config Release --parallel 2`.
Portable tests without JUCE: `cmake -S . -B dsp -DVOICES_DSP_ONLY=ON -DCMAKE_BUILD_TYPE=Release && cmake --build dsp && ctest --test-dir dsp --output-on-failure`.

The UI is drawn in code, not a screenshot. The 100 factory presets are deterministic parameter combinations, not yet auditioned. User presets use timestamp-based names; MIDI CC learn maps channel+CC for rotary controls and persists with project state. Global learn: enable, move a knob, move a MIDI CC. Right-click a knob to learn/clear. Browser search, category and project-local favorites. The host must route MIDI to the effect. French UI defaults to FR. Native Liberty DAW adapter not yet implemented.

DSP limitations: monophonic detector with ~43–47 ms analysis window at common sample rates, ~5–6 ms hop, DC rejection and stereo cancellation fallback; dual delay pitch shifting, not a production-quality formant-preserving algorithm. The new experimental spectral formant engine uses weighted overlap-add FFT, smoothed log spectral envelopes, independent frequency-axis remapping and bounded gain. It is not a validated vocal-tract model. Added fixed processing delay is 1024 samples (2048 above 64 kHz), plus the existing nominal ~10 ms dry delay; actual pitch shifter delay remains variable. No verified live latency claim. Reverb is a simple feedback delay, effects bypass not crossfaded, pitch transitions may click. No real-vocal listening tests, CPU profiling or plugin-host validation. v0.1.0 and v0.2.0 CI passed on macOS ARM64 and Windows x64; v0.3.0 CI and listening validation are required. No signed installers. CI is configured to upload built bundles after tests.

## v0.2.0 Vocal Precision
Shorter detection window; note hysteresis in Natural mode; transition timing on note changes; continuous tolerance deadband; empty custom scales disable tuning; correction meter clears when bypassed. Synthetic tests cover harmonic onset, DC rejection, opposite-phase stereo, correction direction and custom mask. Actual vocal quality and live latency remain unverified; formant control remains spectral colour only.

## v0.3.0 Vocal Formant Engine
Experimental spectral-envelope compensation/remapping (±12 semitones) while keeping the underlying harmonic frequencies. Active on voiced material with tuning enabled; unity path has fixed WOLA delay. Existing parameter ID retained for automation compatibility. Dry/wet branches aligned for the new fixed delay, host reports nominal latency. New tests cover unity impulse reconstruction, finite output and synthetic harmonic-envelope redistribution at three rates. The global power bypass remains immediate for compatibility; real-vocal quality, exact pitch-shifter timing, CPU and host behaviour remain unverified. Live mode, effect crossfades and independent DSP quality review are not completed.

## v0.4.0 Live Performance Engine
Studio HQ retains spectral formants. Live bypasses FFT formants and uses a shorter dual-delay pitch window (nominal dry latency 4 ms + one sample). Mode is persisted and automatable, applied via message-thread latency notification when transport is not reported playing; the engine changes at a block boundary and fades in. Switching modes while recording/playing is not intended; hosts without transport information may apply immediately. Variable wet pitch delay and detector response are not the same as dry latency. Global power bypass now crossfades to latency-aligned raw signal. Natural mode filters pitch centre according to Humanize; hard tune retains raw note tracking. Cubic interpolation, dual micro-pitch voices, four damped parallel reverb lines and smoothed section switches are implemented. Synthetic dry-path impulse tests cover 32/64/128/256 sample grouping at three rates; elapsed dry benchmark is diagnostic, not a full-load real-time guarantee. No host buffer/roundtrip, vocal audition, measured vibrato retention, full-load CPU, or UI screenshot validation yet. Formants unavailable in Live. No signed installers.

## v0.5.0 Vocal Intelligence
Causal energy, brightness, transient hold and detector confidence yield a heuristic vocal state and a smooth correction-protection envelope. This is not a trained phoneme recognizer or reliable speech/singing classifier. Sibilants, low-energy/noisy and transient regions attenuate pitch correction, and spectral envelope processing is gated; other user-selected FX remain active. Note range is observed min/max since prepare, not a voice-type classification. The graph displays detected pitch and estimated corrected pitch (not independent output F0), sampled on the editor timer. Natural note hysteresis follows Humanize; the v0.4 vibrato-centre algorithm remains unchanged. Shared factory values drive both host preset loading and portable tests of 100 individually named presets (synthetic Studio renders, range and numerical checks; not listening tests). Full-load portable block timing reports mean/p99/max at 48 kHz, both modes, 32/64/128/256 samples; no guaranteed realtime performance and no DAW overhead included. Cached smoothing coefficient avoids per-sample recalculation. CI uploads QC logs. Real vocal listening, screenshot layout validation, host automation and MIDI routing tests remain required. v0.4 CI passed; v0.5 pending.

## v0.6 Vocal Studio Pro — development branch
Adds opt-in causal gate/expander, split-band de-esser, compressor, bounded automatic level, four fixed-interval or MIDI-note parallel voices, one parametric bell and a temporary editor A/B comparison. New parameters are off in existing factory presets; no extra reported latency. MIDI mode uses up to four lowest held notes, with a ±24 semitone limit, without sustain handling. Harmonies use the existing delay shifter; quality on real vocals remains unverified. Studio dynamics currently follow correction and harmony (before classic effects), not input preprocessing. Adds a 24-band FFT output spectrum, computed only while the Studio page is visible. Avoids harmony ratio and EQ coefficient calculations while their modules are bypassed. Spectral engine acceleration, multi-band EQ, and advanced menu styling are not implemented. A/B is not persisted and restores APVTS parameters, not preset metadata. UI fit and DSP/host validation pending; no commercial release.

## v0.7 Harmony & Spectral Pro (development)
Adds nearest-scale-note interval snapping (not chord recognition or strict scale-degree transposition), independent gain/pan and experimental per-voice spectral envelope shifts in Studio HQ only, six serial peaking EQ bands with draggable frequency/gain and knob Q, 4096-sample 96-display-band output FFT, complementary three-band dynamics with fixed 250/3500 Hz crossover, and heuristic bass-transient reduction. FFT bit reversal is cached. Factory settings are revised in place, preserving parameter IDs and preset names; old project states are not intentionally rewritten. Formant voices use additional wet-path delay, not reported dry latency; switching formants can cause transients and needs audition. MIDI sustain, adjustable crossovers, stereo-linked dynamics, spectral peak accuracy and actual platform CPU benchmarks remain unverified or not implemented. New tests are synthetic; host compilation, UI and listening validation pending. No commercial release.
